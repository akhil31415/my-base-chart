# 📁 Expected Template Outputs

This directory contains the expected Helm template outputs for all example files. These files serve as a baseline to detect changes in chart behavior.

## 📋 Purpose

- **Regression Testing**: Detect unintended changes in template output
- **Change Tracking**: Track when and how outputs change over time
- **Validation**: Ensure examples produce consistent results
- **Documentation**: Show exactly what each example generates

## 🔧 Usage

### Compare Current Output with Expected

```bash
# Compare all examples
./scripts/compare-outputs.sh

# Compare specific example
./scripts/compare-outputs.sh test-aws-eks
```

### Update Expected Outputs

```bash
# Update all expected outputs
./scripts/update-expected-outputs.sh

# Update specific example
./scripts/update-expected-outputs.sh test-aws-eks
```

### Manual Comparison

```bash
# Generate current output
helm template test-app ./charts/privacera-base-chart \
  -f charts/privacera-base-chart/examples/test-aws-eks.yaml \
  > /tmp/current.yaml

# Compare with expected
diff -u charts/privacera-base-chart/examples/expected-outputs/test-aws-eks-expected.yaml /tmp/current.yaml
```

## 🔄 Workflow

### When to Update Expected Outputs

1. **Chart Changes**: When you modify templates or values
2. **New Examples**: When adding new example files
3. **Intentional Changes**: When you want to change chart behavior
4. **Version Updates**: When updating Helm or dependencies

### Update Process

1. Make your chart changes
2. Run comparison: `./scripts/compare-outputs.sh`
3. Review differences
4. Update expected outputs: `./scripts/update-expected-outputs.sh`
5. Commit both chart changes and expected outputs

### CI Integration

The GitHub Actions workflow automatically:
- Compares current outputs with expected outputs
- Fails the build if outputs differ
- Provides detailed diff information
- Suggests update commands

## 🚨 Important Notes

- **Version Control**: These files should be committed to git
- **Consistency**: All team members should have the same expected outputs
- **Updates**: Update expected outputs when making intentional changes
- **Review**: Always review diffs before updating expected outputs

## 🔍 Troubleshooting

### Output Differs from Expected

1. **Check if change is intentional**:
   - Did you modify templates or values?
   - Is this the expected behavior?

2. **If intentional**:
   ```bash
   ./scripts/update-expected-outputs.sh
   git add charts/privacera-base-chart/examples/expected-outputs/
   git commit -m "chore: update expected outputs after chart changes"
   ```

3. **If unintentional**:
   - Review your changes
   - Check for template errors
   - Verify values.yaml modifications

### Missing Expected Output

```bash
# Generate missing expected output
helm template test-app ./charts/privacera-base-chart \
  -f charts/privacera-base-chart/examples/your-example.yaml \
  > charts/privacera-base-chart/examples/expected-outputs/your-example-expected.yaml
```
